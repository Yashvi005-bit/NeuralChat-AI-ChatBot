# NeuralChat AI – MERN AI Chatbot

NeuralChat AI is a full-stack AI chatbot built using the MERN stack with a primary focus on backend engineering and real-world API integration. The project was developed to gain practical experience in authentication, authorization, secure API handling, cookies, database management, and AI model integration rather than advanced frontend design.

## Key Backend Features

* JWT-based Authentication & Authorization
* Secure cookie handling
* Protected routes and user session management
* AI API integration using Hugging Face models
* MongoDB Atlas database integration
* Persistent chat history storage
* RESTful API architecture
* Error handling and async backend workflows

## Tech Stack

* Frontend: React.js
* Backend: Node.js, Express.js
* Database: MongoDB Atlas
* Authentication: JWT + Cookies
* AI Integration: Hugging Face Inference API

## Project Goal

The primary objective of this project was to strengthen practical backend development skills by implementing real-world concepts such as secure authentication flows, API communication, database integration, and scalable server-side logic.
